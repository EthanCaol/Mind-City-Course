# Win11 必看教程

上大学之前没怎么用过电脑的同学，先把下面两个合集看一遍。每期只有几分钟，讲的是最基础的操作：文件放在哪、软件从哪下、系统出了问题怎么自己排查。

后面几篇文档会直接用到这些内容。比如 WSL2 那篇第一步要在「启用或关闭 Windows 功能」里勾选两个选项，不知道这个窗口怎么打开就没法往下走。所以这一篇排在序号 0。
