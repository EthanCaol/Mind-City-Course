# 图灵完备电路游戏

Turing Complete 是一款从逻辑门开始、逐关搭建出计算机的闯关游戏。每一关给出电路的功能目标和一组基础元件，玩家把它们连接起来，通过这一关的全部测试用例后进入下一关。

关卡按电路的层级排列：先是与、或、非这些逻辑门，接着是加法器、译码器这类组合电路，再到寄存器和内存这类带状态的电路，最后是一台能按指令运行的 CPU。后期游戏会提供一套汇编语言，用来在自己搭建的机器上编写程序。

游戏不需要编程基础，能完成元件之间的连线，并让每一关的测试全部通过，就可以开始。
