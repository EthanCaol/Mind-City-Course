### 一、把 C 语言本身吃透

| 项目             | 内容设想                                                                                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 指针与堆分配     | 自己实现一个堆分配器：用空闲链表管理一大块内存，写出简化版的 `malloc` / `free`。指针的加减、类型转换、指针的指针在这一题里全都要用到 —— 想真正熟悉指针，这是最有效的办法 |
| 位运算与整数表示 | 用打印二进制的办法看懂补码、溢出和移位；再动手拆解、拼装 IEEE 754 浮点数，理解 `0.1 + 0.2` 为什么不等于 `0.3`                                                            |
| 字符串与文本处理 | 自己实现 `strlen` / `strcpy` / `strstr`，再写一个简易 `grep`，顺带理解标准库为什么这么设计                                                                               |
| 内存与调试       | 用 GDB 定位段错误：看调用栈、下条件断点、单步观察变量；再用 AddressSanitizer 抓内存越界、野指针和泄漏。配合《GCC 与 GDB》那篇                                            |

### 二、理解程序怎么跑在机器上

| 项目                      | 内容设想                                                                                                                            |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 最基础的 Linux 命令行工具 | 用系统调用实现 `cat` / `ls` / `wc` / `cp`，理解文件描述符与 `open` / `read` / `write`                                               |
| 进程与管道                | 用 `fork` / `exec` / `wait` 做一个能跑命令的小 shell，再加上管道和重定向                                                            |
| 汇编入门                  | 用 [Compiler Explorer](https://godbolt.org/) 边写 C 边看汇编：左边写代码，右边实时出汇编，两边的行还对应高亮。重点看：参数怎么传、局部变量放在哪、`if` 和 `for` 各自变成了什么、函数调用时栈怎么动。和下一题配合看，取指—译码—执行就不再是抽象的了 |
| 最简单的 CPU 仿真         | RISC-V 的一个子集：取指、译码、执行三步循环，能跑通几条指令就够                                                                     |
| Cache                     | 实现一个软件模拟的 cache：先做直接映射，再加组相联和各种替换策略，用不同的访问模式跑出命中率差异。最后回到真实代码上验证 —— 同一个二维数组，按行遍历和按列遍历的耗时能差出好几倍 |
| 页表                      | 内容待定。可以从「虚拟地址怎么映射到物理地址」入手，做一个软件模拟的页表加缺页处理                                                  |
