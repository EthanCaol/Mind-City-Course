# 作业 5：三数排序

从键盘读入三个整数，按从小到大的顺序输出。

### 示例 1

```text
输入：3 1 2
输出：1 2 3
```

### 示例 2

```text
输入：9 -7 2
输出：-7 2 9
```

### 提示

- 输入一行，三个整数，中间用空格分隔
- 每个整数的绝对值都不超过 1000
- 输出一行三个整数，从小到大排列，用空格分隔，行末换行
- 三个数之间可能有相等的情况
- 除结果外不要输出任何内容，程序不要打印「请输入三个整数」之类的提示文字
