# 作业 15：冒泡排序

从键盘读入 n 个整数，按从小到大的顺序输出。

### 示例 1

输入：

```text
5
3 1 2 5 4
```

输出：

```text
1 2 3 4 5
```

### 示例 2

输入：

```text
4
-2 8 -2 0
```

输出：

```text
-2 -2 0 8
```

### 提示

- 第一行一个整数 n，范围是 1 到 1000
- 第二行 n 个整数，用空格分隔
- 输出一行 n 个整数，从小到大排列，用空格分隔，行末换行
- 冒泡排序一共做 n-1 趟，第 i 趟比较 n-1-i 次，每趟把这一段里最大的数送到末尾
- 相邻两个元素前大后小就交换，交换要借一个临时变量
- 判题只看输出的序列，用别的方法排出同样的结果也算通过
- 除结果外不用输出其他内容
