# 作业 1：整数加法

<p class="doc-meta"><span>负责助教：<strong>曹奕伦</strong></span><span>布置时间：<strong>2026-09-21</strong></span></p>

从键盘读入两个整数，计算并输出它们的和。

### 示例 1

```text
输入：3 5
输出：8
```

### 示例 2

```text
输入：-7 2
输出：-5
```

### 提示

- 输入一行，两个整数，中间用空格分隔
- 两个整数以及它们的和都在 `int` 能表示的范围内
- 输出一行，一个整数，即两数之和，行末换行
- 除结果外不要输出任何内容，程序不要打印「请输入两个整数」之类的提示文字
