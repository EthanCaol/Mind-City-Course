# 在线评测

把作业代码粘进来，几秒后就能看到哪几个测试点没过。**每个测试点的输入、期望输出和你的实际输出都会显示出来**，方便自己定位问题。

!!! warning "代码第一行必须写学号"

    注释符后面只能有学号，多一个字都不行：

    ```c
    // 26803070224
    ```

    学号必须在本课程名单里，否则会被拒绝。姓名不用写——系统按学号从名单里查。

## 判题用的是什么

代码会在服务器的 `isolate` 沙箱里编译运行，和真实的考试环境一致：

- 编译参数固定 `-O2 -std=c11`，和作业要求一致
- 每个测试点限时 1 秒、限内存 256 MB
- 沙箱内没有网络，也读不到别人的文件

同一份代码重复提交不会重复判题，直接返回上次的结果。改了代码再交就会重新判。
